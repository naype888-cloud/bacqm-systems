BACQM Systems Research Group · Instrumentation

Measured, not assumed

Every figure on this site comes from instrumentation at the kernel–hardware interface, under real work, against a baseline that is the same kernel with nothing of ours loaded. The probe never adds load to flatter itself: what the system does while it is observed is what it does.

E1A/B campaigns against the baseline

Protocol. CONTROL is the unmodified kernel with its default fair scheduler. Each campaign alternates CONTROL and BACQM on the same node, n≥3 runs per arm, and reports the median. A campaign counts only if the thermal state stays within 5 °C across its runs; two campaigns failed that test and are excluded.

The step of 26 September · non-invasive measurement

Until 26 September a system thread woke every 1 ms, the same period as the probe, and that favoured the probe. Since then it sleeps when there is no work and no longer perturbs the system. An A/B on 15 October with the same module confirms it: with the 1 ms pulse the probe reads p99 = 159 µs, without it 280 µs. We do not perturb the system to improve a measurement, so the second interval is the one that stands; missed cycles fell from 0.080 % to 0.013 % across the same step. These figures describe the probe, not a workload.
